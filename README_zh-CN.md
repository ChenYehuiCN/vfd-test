# vfd-test

这是一个使用 **STC89C52RC** 驱动 8 位 14 段 VFD 的小项目。

项目最初只是想做一块“能点亮、能显示、还能通过 USB 串口打字”的 VFD 测试板。硬件已经完成打样并验证可用，现将固件、原理图和相关资料开源，供对 VFD、升压电源和经典 8051 单片机感兴趣的朋友参考。

![VFD 实物](vfd.jpg)

## 现在能做什么

- 驱动 8 位 14 段 VFD 显示屏
- 使用 3 片 TBD62783AFG 驱动 VFD 的栅极和阳极段线
- STC89C52RC 负责扫描显示和串口接收
- USB-C 接口通过 CH340N 提供 USB 串口
- 板载由 RTS 控制的自动冷启动电路，配合 STC-ISP 可以一键烧录
- 串口默认参数为 `9600 8N1`
- 固件内置一套 ASCII 字库，收到字符后会向左滚动显示

使用起来很简单：插上 USB，烧录固件，打开串口终端，然后直接输入字符即可。

## 硬件概览

主要器件如下：

- MCU：STC89C52RC-40I-PDIP40
- USB 转串口：CH340N
- VFD 驱动：TBD62783AFG × 3
- 栅极/阳极升压：LMR64010
- 灯丝驱动：DRV8837
- 8051 晶振：11.0592 MHz
- 显示屏：8 位、14 段 VFD（本项目使用 D1319WF）

## 电压参数

下面是这块板子实测下来比较合适的一组工作点。更换 VFD 或电源方案时，不建议直接照搬，最好重新测量和调整。

- 灯丝两端电压：约 **2 Vrms**
- 栅极、阳极对系统地：约 **30 V**
- 栅极/阳极与灯丝之间的平均电压差：约 **25 V**

这里的 25 V 既不是灯丝两端电压，也不是灯丝对地电压，而是栅极/阳极与灯丝之间的平均电压差。灯丝驱动波形相对系统地带有约 5 V 的直流偏置；以栅极、阳极对地 30 V 为例，两者的平均电压差约为 25 V，有助于减小 VFD 鬼影。调试时请分别区分“灯丝两端电压”“灯丝对地电压”和“栅极/阳极与灯丝之间的平均电压差”。

升压部分工作时会发热，输出端也连接着储能电容。测量或改线前请先断电，并给电容留出充分的放电时间。

## VFD 段线与引脚映射

### 常规七段部分

| 常规段 | VFD 引脚 |
| --- | --- |
| a | P4 |
| b | P3 |
| c | P14 |
| d | P5 |
| e | P6 |
| f | P11 |
| g（左半） | P12 |
| g（右半） | P13 |

### 米字形段与中间竖线

| 位置 | VFD 引脚 |
| --- | --- |
| 左上斜线 | P10 |
| 左下斜线 | P7 |
| 右下斜线 | P9 |
| 右上斜线 | P2 |
| 中间竖线（上） | P1 |
| 中间竖线（下） | P8 |

单片机侧的连接关系是：

- `P3.7–P3.2` 对应 VFD `P14–P9`
- `P2.7–P2.0` 对应 VFD `P1–P8`

字库位于 [`vfd-test-firmware/main.c`](vfd-test-firmware/main.c)。如果更换了段线接法，主要修改这个文件即可。

## 固件使用

上电后，固件会循环扫描 8 个显示位。每收到一个串口字符，就将其放入显示缓冲区，并使已有内容整体向左移动一位。

在 Linux 下可以使用 minicom：

```bash
minicom -D /dev/ttyUSB0 -b 9600
```

也可以使用其他串口工具，参数设置为：

```text
波特率：9600
数据位：8
校验位：None
停止位：1
流控：None
```

终端是否回显由串口软件决定。固件主要负责接收字符并显示，不保证将字符原样回传到主机。

## 编译与烧录

固件工程使用 Keil C51 开发，工程文件为：

```text
vfd-test-firmware/vfd-test-firmware.uvproj
```

编译后生成的 HEX 文件位于：

```text
vfd-test-firmware/Objects/vfd-test-firmware.hex
```

使用支持 STC89C52RC 的烧录工具写入该 HEX 文件即可。板载 USB 转串口芯片的 RTS 信号连接了自动冷启动电路，因此使用 STC-ISP 时可以一键自动进入编程模式、擦除并烧录，无需手动反复断电上电。

如果使用其他烧录器，冷启动和串口连接方式可能不同，请按照对应烧录器的说明操作。

## 注意事项

这是一块实验性质的第一版硬件，参数和布局都是围绕本项目使用的 VFD 调整的。虽然 VFD 电源只有几十伏，但升压电路、储能电容和驱动波形仍可能造成烫伤、短路或器件损坏。

电路工作时请勿用手触摸栅极、阳极、灯丝驱动或相关测试点。人体会导电，触摸可能使栅极、阳极电压经人体传导到单片机，导致单片机工作异常；也可能将电压传导到灯丝供电的 LDO，使灯丝电压升高，严重时会出现灯丝发红的情况。测量或改线前请先断电，并给电容留出充分的放电时间；使用示波器时也要特别注意探头地夹的连接位置。

如果你复刻这块板子，建议根据所使用的屏管型号重新调整灯丝电压、栅极/阳极电压和限流参数。
