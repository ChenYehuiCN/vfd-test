# vfd-test

这是一个基于 **STC89C52RC** 的开源 VFD 测试板项目。它可以驱动 8 位 14 段 VFD，通过 USB 串口接收字符，并将电源、高压驱动和显示扫描电路集成在一块板上。

## 项目概览

信号链路很直接：USB-C → CH340N → STC89C52RC → TBD62783AFG → VFD。单片机负责扫描 8 个显示位，并通过串口接收可显示的 ASCII 字符。CH340N 的 RTS 信号还连接到板载自动冷启动电路，因此使用 STC-ISP 时无需手动反复断电上电。

## 功能

- 8 位 14 段 VFD，固件内置可显示 ASCII 字库
- 3 片 TBD62783AFG 驱动 VFD 栅极和阳极段线
- 通过 CH340N 提供 USB-C 串口
- 默认串口参数：`9600 8N1`
- RTS 控制的自动冷启动电路，支持 STC-ISP 一键烧录
- 栅极/阳极升压电源和专用灯丝驱动集成在同一块板上

## 硬件组成

| 功能 | 器件 |
| --- | --- |
| MCU | STC89C52RC-40I-PDIP40 |
| USB 转串口 | CH340N |
| VFD 驱动 | TBD62783AFG × 3 |
| 栅极/阳极升压 | LMR64010 |
| 灯丝驱动 | DRV8837 |
| 晶振 | 11.0592 MHz |
| 显示屏 | D1319WF，8 位 14 段 VFD |

## 电压工作点

下面是这块板子配合当前屏管实测下来比较合适的一组工作点。更换 VFD 或电源方案时，不建议直接照搬，最好重新测量和调整。

- 灯丝两端电压：约 **2 Vrms**
- 栅极、阳极对系统地：约 **30 V**
- 栅极/阳极与灯丝之间的平均电压差：约 **25 V**

这里的 25 V 既不是灯丝两端电压，也不是灯丝对地电压，而是栅极/阳极与灯丝之间的平均电压差。灯丝驱动波形相对系统地带有约 5 V 的直流偏置；以栅极、阳极对地 30 V 为例，两者的平均电压差约为 25 V，有助于减小 VFD 鬼影。调试时请分别区分“灯丝两端电压”“灯丝对地电压”和“栅极/阳极与灯丝之间的平均电压差”。

## 安全说明

> **警告**
>
> 升压电路工作时会发热，输出端的储能电容在断电后仍可能带电。板子工作时，请勿触摸栅极、阳极、灯丝驱动和相关测试点。
>
> 人体会导电。触摸电路可能使栅极、阳极电压经人体传导到单片机，导致单片机工作异常；也可能将电压传导到灯丝供电的 LDO，使灯丝电压升高，严重时会出现灯丝发红的情况。测量或改线前请先断电，并给电容留出充分的放电时间；使用示波器时也要特别注意探头地夹的连接位置。

## 快速开始

### 1. 编译与烧录

固件工程使用 Keil C51 开发：

```text
vfd-test-firmware/vfd-test-firmware.uvproj
```

编译后生成的 HEX 文件位于：

```text
vfd-test-firmware/Objects/vfd-test-firmware.hex
```

使用支持 STC89C52RC 的烧录工具写入该 HEX 文件即可。CH340N 的 RTS 信号连接了自动冷启动电路，因此使用 STC-ISP 时可以一键自动进入编程模式、擦除并烧录，无需手动反复断电上电。

### 2. 通过串口发送字符

在 Linux 下可以使用 minicom：

```bash
minicom -D /dev/ttyUSB0 -b 9600
```

| 参数 | 值 |
| --- | --- |
| 波特率 | 9600 |
| 数据位 | 8 |
| 校验位 | None |
| 停止位 | 1 |
| 流控 | None |

固件每收到一个可显示 ASCII 字符，就将其追加到显示缓冲区，并使已有内容整体向左移动一位。终端是否回显由串口软件决定；固件不会把收到的字符回传到主机。

## VFD 段线映射

### 常规七段部分

| 常规段 | VFD 引脚 |
| --- | --- |
| a | P4 |
| b | P3 |
| c | P14 |
| d | P5 |
| e | P6 |
| f | P11 |
| g（左半） | P12 |
| g（右半） | P13 |

### 米字形段与中间竖线

| 位置 | VFD 引脚 |
| --- | --- |
| 左上斜线 | P10 |
| 左下斜线 | P7 |
| 右下斜线 | P9 |
| 右上斜线 | P2 |
| 中间竖线（上） | P1 |
| 中间竖线（下） | P8 |

单片机与 VFD 的连接关系：

- `P3.7–P3.2` 对应 VFD `P14–P9`
- `P2.7–P2.0` 对应 VFD `P1–P8`

95 个可显示 ASCII 字符的字库位于 [`vfd-test-firmware/main.c`](vfd-test-firmware/main.c)。如果更换了段线接法，主要修改这个文件即可。
